Auto Detect 検出アルゴリズム詳細

色だけに依存せず、幾何形状・連続性・傾きから最大16曲線を軽量追跡する仕組み

目的処理工程追跡再結合選別レビュー制約

1. 目的と設計方針

AutoSeriesDetectorは、ROIへ切り出されたグラフ画像から複数の系列を自動検出します。カラー曲線だけでなく、すべて黒線・同色曲線でも動作させるため、色は候補画素を漏らさないための補助とし、系列の同一性は位置・傾き・連続性で判断します。

方針理由
学習モデルを使わないEXEサイズ、起動時間、推論時間を増やさず、既存OpenCvSharpだけで配布する。
列方向に走査する一般的な特性グラフをY=f(X)として扱い、2次元全探索を列候補の追跡へ縮約する。
人が最終選択する文字、凡例、交差、完全重複など画像だけでは一意に決められないケースを安全に扱う。

2. 全処理パイプライン

1. BGR正規化Gray/BGRA/BGR入力を3ch BGRへ統一
2. インクマスク暗色画素と有彩色画素のOR
3. 長線除去画像の65%以上を横断するグリッド候補を除去
4. 枠除去外周最大3pxを候補外にする
5. 列候補化各X列の連続画素を中心Yへ圧縮
6. 複数追跡位置と傾き予測で候補を接続
7. 断片再結合欠損前後の位置・傾きが一致する区間を連結
8. 品質フィルタ長さ、密度、重複を評価
9. 平滑化1-2-1重みでYを平滑化
10. レビューユーザーが採用系列だけ確定

3. インク画素の抽出

3.1 暗色マスク

BGRをGrayへ変換し、CurveThreshold以下を前景とする反転二値化を行います。

dark(x,y) = 1 if Gray(x,y) ≤ CurveThreshold, otherwise 0

3.2 有彩色マスク

HSV空間で彩度が45より大きく、明度が250未満の画素を拾います。黒線は暗色マスク、比較的明るいカラー線は有彩色マスクで取得できます。

colored(x,y) = 1 if 0≤H≤179, 45≤S≤255, 0≤V≤249

最終候補は ink = dark OR colored です。色相による系列分離は行いません。

3.3 グリッドと枠

幅の65%以上の水平カーネル、高さの65%以上の垂直カーネルでMorphological Openを行い、長い直線だけを抽出してinkから減算します。短いカーネルを使わないのは、水平に飽和した特性曲線をグリッドとして消さないためです。

曲線がグリッドと完全に重なる区間は、グリッド除去によって一時的に欠損する可能性があります。そのため後段に欠損許容と断片再結合があります。

4. 列候補と複数トラック

4.1 列候補の中心

各X列で連続している前景区間 [yStart, yEnd] を1候補へまとめます。太線を複数点として扱わず中心線に近づけます。

candidateY = (yStart + yEnd) / 2

4.2 次位置の予測

既存トラックは最後のY、推定傾き、連続欠損列数から次のYを予測します。

predictedY = lastY + slope × (missedColumns + 1)

候補のうち予測Yに最も近く、許容距離以内の点を接続します。候補がなければ欠損列数を増やし、6列を超えたトラックは通常追跡を終了します。

allowedDistance = maxJump + 1.5 × missedColumns
maxJump = clamp(TraceSearchBandWidth / 3, 3, 8)

手動トレース用の探索幅をそのまま使わず最大8pxに制限することで、欠損時に隣の曲線へ吸着する誤接続を抑えています。

4.3 傾きの更新

新しい点を接続したとき、瞬間傾きへ完全に置き換えず指数移動平均で更新します。

measuredSlope = (newY − previousY) / Δx
slopeNew = 0.7 × slopeOld + 0.3 × measuredSlope

初回の接続だけは測定傾きをそのまま採用します。複数のトラックが交差点の同じ候補を一時共有できるため、交差後は各自の傾き予測で分岐できます。

5. 欠損区間の再結合

グリッドとの重なりなどで1曲線が前半・後半に分断された場合、終了トラックから後続トラックの先頭を予測します。

predictedStartY = first.lastY + first.endSlope × (gap + 1)
yError = |second.firstY − predictedStartY|
slopeError = |second.startSlope − first.endSlope|

候補間隔は最大 max(12px, imageWidth×0.12)。Y誤差と傾き誤差が制限内なら、次のスコアが最小の後続断片を結合します。

mergeScore = yError + 8 × slopeError + 0.02 × gap

傾き誤差は0.55以下、Y許容誤差は概ね5〜12px相当（maxJumpにより上限）です。これにより、同じ高さで再出現する曲線は結び、下側の別曲線へ急落する接続は避けます。

6. 品質フィルタと平滑化

判定条件目的
水平スパンmax(MinCurveLength, imageWidth×20%)以上文字、短い凡例線、点ノイズを除く。
点密度pointCount ≥ horizontalSpan×45%疎すぎる断片を除く。点線や小欠損は許容する。
重複短い方の60%以上でXが重なり、その80%以上がY差2.5px以内太線や交差共有で生じたほぼ同一トラックを1本にする。
最大数16系列UI色パレットと計算量を制限する。

採用前に1-2-1の重み付き3点平滑化を行います。

y′[i] = (y[i−1] + 2y[i] + y[i+1]) / 4

最後に平均Yの小さい順、すなわち画面上側から並べます。

7. レビュー、実座標化、選択維持

  1. 候補を16色パレットでROI画像へ重ねる。
  2. ユーザーがチェックを外した候補は灰色表示にする。
  3. OK後、選択系列だけを_detectedPixelSeriesへ保存する。
  4. PixelConverterで線形/対数軸の実値へ変換する。
  5. Extraction Settings変更やノイズ除去で再検出した場合、以前の選択系列とX重複・平均Y距離を比較し、対応する系列だけを残す。

再検出で未選択系列が復活しないよう、重複が短い方の35%以上かつ平均Y距離が設定幅から算出した3〜8px以内の系列だけを以前の選択と同一とみなします。

8. 計算量と配布サイズ

画像幅W、高さHに対し、マスク生成と列候補抽出は概ねO(W×H)。追跡は各列の候補数とアクティブトラック数に比例します。ニューラルネットワークや追加ランタイムはなく、既存OpenCvSharpを利用するためAuto Detect追加による大きな配布サイズ増加はありません。

9. 想定制約と改善余地

ケース現在の挙動将来案
完全に重なる同一線種画像上は1本なので本数を確定できない。凡例・前後区間・ユーザー指定本数を補助情報にする。
垂直に近い曲線Y=f(X)の列追跡では1列に複数Yが入り不利。骨格グラフ探索または走査方向の自動切替。
文字が長く連なる長さ条件を超えると候補になる場合がある。OCRなしの文字形状フィルタ、凡例領域指定。
複雑な交差・分岐傾きの滑らかさを優先するが一意でない。交差点接続パターンの手動切替UI。
大きく途切れた点線12%を超える欠損は別系列になる。線種周期推定とユーザーによる結合操作。
