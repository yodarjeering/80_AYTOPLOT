AutoPlot ソースコードガイド

WPF / MVVM / OpenCvSharpで構成されたグラフ画像数値化アプリの現行ソース構成

全体構成起動・設定Views ViewModelsModels画像処理 ServicesUtils旧・予約コード

1. 全体構成

MainViewModelが画面遷移と処理状態を統括し、ImageProcessingServiceを介してImageProcessorへ基本抽出を依頼します。複数曲線の自動検出はAutoSeriesDetector、手動補助はSeriesTraceViewModel、確認・採否はAutoSeriesReviewViewModelが担当します。

画像入力 → ROI検出 → 軸設定 → 基本曲線抽出 ├─ Auto Detect → 候補レビュー → 選択系列を実座標化 ├─ Manual Trace → ガイド近傍探索 → 実座標化 └─ Noise Removal → 再抽出・選択系列維持 ↓ オーバーレイ / グラフ描画 / TSVコピー

このガイドは bin、obj、.vs の生成物を対象外とし、リポジトリ内の手書きソースを説明します。

4. ViewModels

ファイルクラス責務と重要な状態
ViewModels/MainViewModel.csMainViewModel画像、ROI、軸、抽出設定、表示状態、選択系列を所有する中核。全コマンド、ダイアログ開閉、基本抽出、自動/手動系列抽出、実座標変換、再検出時の選択維持、グラフ描画、コピー文字列生成を統括する。
ViewModels/AxisAxisCalibrationDialogViewModel.csAxisCalibrationDialogViewModel軸範囲、対数フラグ、テーマ候補と選択テーマを保持する。ファイル名にAxisが重複しているがクラス名は正常。
ViewModels/ExtractionSettingsDialogViewModel.csExtractionSettingsDialogViewModelExtractionSettingsを編集用プロパティへ展開し、範囲検証後に新しい設定オブジェクトを生成する。
ViewModels/NoiseRemovalViewModel.csNoiseRemovalViewModelノイズマスク、プレビュー、Undo/Redoスタックを管理する。WriteableBitmapを再利用してペン描画のちらつきを抑える。
ViewModels/SeriesTraceViewModel.csSeriesTraceViewModel手動ガイド系列、現在系列番号、トレース状態、Undo/Redo、確定結果を管理する。
ViewModels/AutoSeriesReviewViewModel.csAutoSeriesReviewViewModel
AutoSeriesCandidate		自動候補ごとの採用状態とプレビューを管理する。選択候補のみをMainViewModelへ返し、MatをDisposeする。
ViewModels/CurveDataCopyDialogViewModel.csCurveDataCopyDialogViewModelヘッダーとデータを分離し、表示用固定幅テキストとコピー用TSVを別々に保持する。
ViewModels/SeriesCountDialogViewModel.csSeriesCountDialogViewModel系列数1項目だけを保持する旧/補助ViewModel。

Models/ExtractionSettings.csExtractionSettings二値化、ノイズマスク、手動/自動探索幅、最小長、平滑化、外れ値除去の設定値。
Models/DisplayState.csDisplayStateNone、Original、AxisCalibrated、NoiseRemoval、GraphPlotの表示状態列挙。
Models/AppSettings.csAppSettings永続化対象のアプリ設定。現在はテーマを保持する。
Models/AppTheme.csAppThemeLight、Dark、ChocoMintのテーマ列挙。

6. ImageProcessing

ファイル役割アルゴリズム概要
ImageProcessing/ImageProcessor.cs基本画像処理長い縦横線からROIを決定する。ROI内を二値化し、グリッド除去、ノイズマスク、連結成分フィルタ、列ごとの中央値、外れ値除去、移動平均、実座標変換、オーバーレイ生成を行う。
ImageProcessing/AutoSeriesDetector.cs複数系列自動検出暗色/有彩色インクマスク、長線除去、列候補中心、位置・傾き予測トラッキング、欠損許容、断片再結合、長さ/密度/重複フィルタ、平滑化を行う。詳細はAutoDetectAlgorithm.htmlを参照。
ImageProcessing/Helpers/PixelConverter.cs座標変換ピクセル範囲を線形または対数の実値範囲へ写像する。Y軸反転にも対応する。

7. Services

ファイル役割説明
Services/ImageProcessingService.cs画像処理FacadeMainViewModelとImageProcessorを分離する。ROI検出、プロット処理、ROI強調表示、ノイズマスク適用を公開する。
Services/AppSettingsService.cs設定永続化JSON設定をユーザー領域から読み書きし、失敗時は既定設定へフォールバックする。
Services/AppThemeManager.csテーマ適用テーマ別PaletteからDynamicResource Brushを差し替え、PlotColorsにもテーマを伝える。

8. Utils

ファイル役割説明
Utils/OpenCvUtils.cs画像変換・グラフ描画画像ロード、BitmapSource/Mat変換、単一/複数系列グラフ描画を提供する。線形目盛りは1/2/2.5/5×10ⁿから見やすい刻みを選び、対数目盛りは10の累乗を使う。
Utils/PlotColors.cs描画色最大16系列の重複しない色、テーマ別の背景・グリッド・軸・文字・ROI・ノイズマスク色をWPF Brush/OpenCV Scalarへ変換する。

10. 変更時の依存関係ガイド

  • 抽出ロジック変更：ImageProcessorまたはAutoSeriesDetectorを変更し、設定追加時はModel → DialogViewModel → XAML → MainViewModelの順に接続する。
  • 色変更：UI色はAppThemeManager、グラフ/系列色はPlotColorsを変更する。
  • 出力形式変更：MainViewModel.BuildCurveDataTextとCurveDataCopyDialogViewModelを確認する。
  • Matはネイティブメモリを持つため、所有者を明確にしusing/Disposeを維持する。
